# Segítő Hősök

Ingyenes játék családoknak: a gyerekek a valódi segítségükért (kapálás, rendrakás, bevásárlás, tanulás) XP-t kapnak, képességeik szintet lépnek, az eszközeik fejlődnek (fakapától a gyémántkapáig). Saját hőst készíthetnek, kis társat fogadhatnak be, a gyűjtött érmékért pedig valódi jutalmat (például fagyizást) válthatnak be.

A szülő PIN-kóddal hagyja jóvá a elvégzett feladatot, és saját feladatokat, jutalmakat is felvehet.

Megnyitás: https://segitohosok.github.io/Segito-hosok/

Első indításkor a szülő állít be PIN-kódot. Regisztráció nincs, az adatok csak az adott eszközön, a böngészőben tárolódnak.

Kipróbálás: 3 hétig használjátok, és írjátok meg, mi tetszett, mi hiányzik!
